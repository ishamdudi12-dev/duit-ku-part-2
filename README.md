# Duit Ku - Game Simulasi e-Wallet

Aplikasi web simulasi e-Wallet bergaya DANA/E-Wallet populer dengan **saldo tak terbatas** yang digunakan hanya untuk hiburan, game, dan hiburan (gaya-gayaan).

## 🚀 Fitur Utama
- **Saldo Unilimited/Simulasi**: Saldo awal Rp 999 Miliar.
- **Simulasi Transfer Realtime**: Bisa transfer ke nama/rekening bebas dan saldo langsung berkurang secara interaktif.
- **Klaim Rezeki**: Fitur untuk menambah saldo simulasi kapan saja.
- **Sembunyikan Saldo**: Fitur icon mata untuk menyembunyikan nominal saldo.
- **Mobile First Design**: Desain responsif menyerupai layar HP.

## 🛠️ Cara Menjalankan
Cukup buka berkas `index.html` di browser favorit kamu atau akses via **GitHub Pages**.

> **Catatan**: Aplikasi ini **murni game / hiburan** dan tidak menggunakan uang asli sama sekali.
